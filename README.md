---  PizzaCraft  ---

PizzaCraft — учебный проект на C#, моделирующий работу пиццерии и процесс формирования заказа.
Проект создавался для практики объектно-ориентированного программирования: основные части предметной области представлены отдельными классами, которые отвечают за пиццы, ингредиенты, тесто, бортики, меню и заказы.

-  Возможности:  -
/выбор готовой пиццы из меню;
/создание собственной пиццы из доступных ингредиентов;
/создание комбинированной пиццы из двух половинок;
/выбор размера пиццы;
/добавление бортика с проверкой его совместимости;
/расчёт стоимости пиццы в зависимости от состава и размера;
/формирование заказа из нескольких позиций;
/расчёт итоговой стоимости заказа;
/возможность указать комментарий к заказу;
/оформление заказа на ближайшее время или на выбранные дату и время.


-  Основные сущности  -
В проекте используются отдельные классы для разных частей системы:
\Pizza — пицца, её размер, основа, ингредиенты и бортик;
\Ingredient — ингредиенты;
\Dough — варианты основы;
\Crust — бортики;
\Menu — доступные позиции и создание пиццы;
\Order — формирование и расчёт заказа;
\CombiPizza — пицца, состоящая из двух разных половинок.
\Объекты, которые могут быть добавлены в заказ, работают через общий интерфейс IOrderable.
